# Maya AI Systems Website v2

New portfolio/proof site for Maya Buto.

## Direction

Visual system: cinematic graphite/fog/silver/white with restrained violet accents.
Core narrative: complexity → structure → system → evidence → real impact.

## Content rules

- No public project pricing.
- Commercial proof may state paid B2B delivery without disclosing amount.
- Public claims must be supported by Maya's canonical source-of-truth documents or inspectable public repositories.
- Vladimir case is presented generically as a commercial field-measurement operational system; client-identifying and confidential business data stay out of the public site.
- FieldOps AI and Market Jury are presented with honest project-status language.

## Current implementation stage

Phase 1 scaffold is in place:
- Next.js 16 / React 19 / TypeScript / Tailwind 4 foundation
- Home route delegates to `src/views/home.tsx`
- content separated into `src/data/site-content.ts`
- first responsive static composition for hero, commercial case, system classes, selected systems, principles, notes, about and contact

Complex motion, WebGL, particle scenes, polished typography and final case-detail pages are intentionally not implemented yet.
